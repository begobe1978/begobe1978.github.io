# Bernardo Gómez Bey — web personal

Sitio estático para `https://bernardogomezbey.com/`.

## Estructura

- `index.html`: contenido, semántica y metadatos SEO.
- `css/styles.css`: estilos y puntos de ruptura responsive.
- `assets/`: monograma y dos portadas (sin duplicados).
- `CNAME`: dominio de GitHub Pages.
- `robots.txt` y `sitemap.xml`: indexación.

## Publicación

Configurar GitHub Pages desde `main` y `/(root)`, con dominio personalizado `bernardogomezbey.com`. Confirmar HTTPS tras la publicación. No tocar DNS si continúa apuntando a GitHub Pages.

## Mantenimiento

Editar HTML y CSS por separado. No hacen falta Node, compiladores, dependencias ni JavaScript para el funcionamiento. Revisar enlaces externos periódicamente.
